# দীর্ঘশ্বাস — পূর্ণ Narration স্ক্রিপ্ট (খসড়া ১)

> কণ্ঠ: আব্দুল আজিজ কায়েস (ক্লোন)
> ধরন: শান্ত, রাতের বেলা নিজের জীবন মনে করার মতো। কোনো মোটিভেশনাল সুর নয়।
> চিহ্ন: `/` = ছোট বিরতি (~০.৫ সে.), `//` = লম্বা বিরতি (~১.৫ সে.), `[নীরবতা]` = narration নেই, শুধু দৃশ্য ও শব্দ।
> `⚠️` চিহ্নিত লাইন = তথ্য এখনও নিশ্চিত নয়; নিশ্চিত না হলে বাদ যাবে।

## ACT I — স্বপ্ন দেখা ছেলেটা

### Scene 01 — শুরু (হাজীগঞ্জ, ভোর)
[নীরবতা — ফ্যানের শব্দ, কলমের শব্দ, দূরে পাখি]

**টাইটেল:** দীর্ঘশ্বাস / *একটি জীবনের গল্প*

### Scene 02 — পরিশ্রম
> তখন আমার পৃথিবীটা খুব ছোট ছিল। //
> কয়েকটা বই, / একটা টেবিল, / আর সামনে রাখা কিছু স্বপ্ন। //
> আমি জানতাম না, স্বপ্ন কত বড় হতে হয়। /
> শুধু জানতাম— / আমাকে চেষ্টা করতে হবে।

### Scene 03 — দাখিলের ফলাফল (২০২২)
[নীরবতা — ফোনে ফলাফল পড়া, ছোট্ট হাসি। তারপর আসল সার্টিফিকেট, শুধু GPA 5.00 হাইলাইট]
> কিছুদিনের পরিশ্রমের একটা উত্তর সেদিন পেয়েছিলাম। //
> দাখিল। / জিপিএ পাঁচ। //
[আসল ট্যালেন্টপুল তালিকা — শুধু নিজের লাইন হাইলাইট, অন্যদের নাম ঝাপসা]
> ট্যালেন্টপুলে বৃত্তি। / চট্টগ্রাম বিভাগের তালিকায় / পাঁচ নম্বরে আমার নাম। //
> সেই বয়সে একটা ভালো ফলাফলই মানুষকে বিশ্বাস করায়— / সে আরও দূর যেতে পারবে।

### Scene 04 — ঢাকার ডাক
> তারপর এলো ঢাকার ডাক। //
> চেনা গণ্ডি পেরিয়ে, / ঢাকা কলেজ। //
> নতুন শহর। / নতুন মানুষ। / নতুন স্বপ্ন। //
> আর সেই ছেলেটা তখনও জানত না— / এই শহরই একদিন তাকে / নিজের সঙ্গে সবচেয়ে কঠিন লড়াইটা শেখাবে।

## ACT II — শহর আর ফাটল

### Scene 05 — নতুন মুখ
> অচেনা শহরটা ধীরে ধীরে অচেনা থাকল না। //
> কিছু মুখ পরিচিত হলো। / আর পরিচিত মুখগুলো একসময় / হয়ে গেল গল্পের সঙ্গী।
[মেসের ঘর, "ONLY STUDY / NEVER GIVE UP" লেখা টেবিল — narration নেই]

### Scene 06 — প্রথম ফাটল (টেস্ট পরীক্ষা, বৃষ্টি, ধানমন্ডি)
[বাস থেকে নামা পর্যন্ত নীরবতা — শুধু বৃষ্টি আর রাস্তা]
> কিন্তু নতুন শহরের গল্পটা / সবসময় এত সুন্দর ছিল না। //
> টেস্ট পরীক্ষায় / রসায়নে ফেল করেছিলাম। //
> মাত্র এক নম্বরের জন্য। //
> আর সেদিন মনে হয়েছিল— / হয়তো আমিই ফেল করে যাচ্ছি।
[কাগজ পানিতে পড়া — লম্বা নীরবতা, শুধু বৃষ্টি]

### Scene 07 — পরের সকাল
> একটা ফলাফল মানুষকে ভেঙে দিতে পারে। //
> কিন্তু ভেঙে যাওয়ার পরও / মানুষ আবার বই খুলে বসে। //
> কারণ হেরে যাওয়া / আর হাল ছেড়ে দেওয়া— / দুটো এক জিনিস নয়।

### Scene 08 — একের পর এক
> সবকিছু এত সহজে বদলায়নি। //
> একটা একটা করে ধাক্কা আসছিল। /
> আর আমি ধীরে ধীরে বুঝতে শিখছিলাম— /
> শুধু চেষ্টা করলেই / সবসময় ফল পাওয়া যায় না।
[রাত ৪:১৯-এর টেবিল, লাল ল্যাম্প, কফির কাপ — match cuts, narration নেই]

### Scene 09 — শেষ লড়াই
> সময় এগিয়ে যাচ্ছিল। //
> পেছনে পড়ে থাকল অনেক ভুল, / অনেক ব্যর্থতা। //
> সামনে তখন একটাই পরীক্ষা। / আর তার ওপারে— / একটা অজানা ভবিষ্যৎ। //
> তাই আবার শুরু করলাম।

### Scene 10 — HSC ফলাফল (১৫ অক্টোবর ২০২৪)
[নীরবতা — আসল ট্রান্সক্রিপ্ট; GPA 5.00 আর Chemistry A+ হাইলাইট]
> যে রসায়নে একদিন / এক নম্বরের জন্য ফেল করেছিলাম— //
> সেই রসায়নেই / এ-প্লাস। //
> জিপিএ পাঁচ। //
> সেদিন বুঝেছিলাম, / একটা পরীক্ষার ফল / পুরো মানুষটার ফল নয়।
[ফাঁকা করিডোর দিয়ে হেঁটে যাওয়া — বিদায়, narration নেই]

## ACT III — যখন পুরোনো পরিকল্পনা ভাঙে

### Scene 11 — ভর্তির স্বপ্ন
> ⚠️ স্বপ্ন ছিল / একদিন ডাক্তার হব।
[স্মারক: "Wish to be the Best Doctor in Future" — শুধু ইনসার্ট]
> ভেবেছিলাম, পরের দরজাটা নিজে থেকেই খুলে যাবে। //
> যা করার কথা, করেছিলাম। / পড়েছিলাম। / চেষ্টা করেছিলাম। //
> কিন্তু জীবন সবসময় / আমাদের লেখা ক্রম মেনে চলে না।

### Scene 12 — যে দরজাগুলো খুলল না (মার্চ ২০২৫)
[আসল ঢাবি ফলাফল — শুধু "অনুত্তীর্ণ" ফোকাসে, বাকি ঝাপসা। লম্বা নীরবতা]
> কিছু দরজা খুলল না। //
> যেগুলো খুলবে বলে / অনেকদিন অপেক্ষা করেছিলাম। //
> সেদিন প্রথম বুঝলাম— / প্রশ্নটা আর "কেন হলো না" থাকে না। //
> প্রশ্নটা হয়— / "এখন কী করব?"

### Scene 13 — নীরব সময়
[নীরবতা — ঘর, সিলিং, রাত, ফোন। শেষে রেললাইন ধরে হাঁটা]

## ACT IV — নতুন করে গড়া

### Scene 14 — অন্য একটা পথ
> হয়তো আমি আমার জীবনের / পুরোনো প্রশ্নটার উত্তর খুঁজছিলাম। //
> যদি কোনো দরজা না খোলে— //
> তাহলে কি / নিজের একটা দরজা বানানো যায়?

### Scene 15 — সন্ধান
> সমস্যা দেখলে / শুধু অভিযোগ না করে, / তার একটা সমাধানও খোঁজা যায়। //
> ⚠️ রক্তের প্রয়োজনে / মানুষ কতটা অসহায় হয়ে পড়ে, / সেটা আমি দেখেছি। //
> তাই ভাবলাম, / প্রযুক্তি যদি মানুষের কঠিন সময়ে / একটু হলেও কাজে লাগে— / তাহলে চেষ্টা করে দেখি। //
> সেখান থেকেই / সন্ধানের শুরু। //
[সন্ধানের ইন্টারফেস — নীরবতা]
> এটা হয়তো এখনও / অনেক দূরের একটা পথ। //
> কিন্তু এবার অন্তত / আমি শুধু স্বপ্ন দেখছিলাম না। / কিছু একটা তৈরি করছিলাম।

### Scene 16 — MOVE
> মানুষকে শুধু একটা সংখ্যা দেখিয়ে / সবসময় নড়ানো যায় না। //
> কখনো কখনো একটা গল্প দরকার। / একটা গন্তব্য দরকার। //
> সেখান থেকেই মুভের ভাবনা— / যতটা পথ হাঁটব, / ততটাই এগিয়ে যাব / বাংলাদেশের একটা যাত্রায়। //
> আমি শিখছিলাম— / একটা মানুষ কেন / কোনো একটা কাজ করতে চায়।

### Scene 17 — Mino ও তৈরির রাতগুলো
> তারপর মিনো। //
> যে প্রশ্নগুলো নিয়ে / একসময় আমি নিজে দিশেহারা ছিলাম— / কী পড়ব, কোথা থেকে শুরু করব, ভুলটা কোথায়— //
> সেই প্রশ্নগুলোর পাশে / একজন সঙ্গী বানানোর চেষ্টা। //
> ভুল হবে। / আবার করতে হবে। / কখনো আটকে যাব। / আবার শিখতে হবে। //
> কিন্তু প্রতিটা চেষ্টা / আমাকে একটু একটু করে / নিজেকে বুঝতে শেখাচ্ছিল।

## ACT V — পথ এখনও খোলা
